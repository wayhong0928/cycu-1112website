# 個人履歷網站 - wayhong

> 中原大學111學年度第二學期 網路程式設計課程作業

## 📋 專案簡介

這是一個多頁式個人履歷網站，展示個人資訊、專業能力、程式技能及相關經歷。網站採用響應式設計，提供良好的使用者體驗。

## ✨ 網站特色

- 📱 響應式網頁設計，支援多種裝置瀏覽
- 🎨 現代化的視覺設計與使用者界面
- 🔗 完整的頁面導覽系統
- 🎵 特色彩蛋：五月天歌詞收藏頁面

## 📄 頁面說明

本網站共包含 10 個頁面：

### 主要頁面

1. **index.html** - 網站首頁，提供導覽入口
2. **about.html** - 關於威宏
   - 個人簡介與背景
   - 學經歷介紹
   - 社團經歷（緊急醫療救護社）
   - 證照資訊（FR、EMT-1）

3. **skills.html** - 專業能力
   - 電腦軟體應用乙級證照
   - 中文輸入速度相關技能
   - 其他專業技能展示

4. **program.html** - 程式技能
   - 程式語言能力
   - 技術專長展示

5. **exp.html** - 個人經歷總覽

### 經歷子頁面

6. **exp_1101.html** - 1101 學期經歷
7. **exp_1102.html** - 1102 學期經歷
8. **exp_emt.html** - 緊急醫療救護相關經歷
9. **exp_eooiapt.html** - 產學營運處工讀經歷

### 特色頁面

10. **mayday.html** - 五月天歌詞收藏
    - 喜愛的五月天歌曲與歌詞分享

## 🚀 使用方式

1. **直接開啟**

   ```
   直接在瀏覽器中開啟 index.html 即可瀏覽
   ```

2. **本地伺服器** （建議）

   ```bash
   # 使用 Python 啟動簡易伺服器
   python -m http.server 8000

   # 或使用 Node.js（需安裝 http-server）
   npx http-server
   ```

   然後在瀏覽器打開 `http://localhost:8000`

3. **瀏覽導覽**
   - 點擊頁面頂部導覽列切換不同頁面
   - 首頁有隱藏彩蛋連結通往五月天歌詞頁面 🎵
